# Исправление ошибки formatTimeRemaining на разных доменах

## 🚨 Проблема

Ошибка `SyntaxError: Importing binding name 'formatTimeRemaining' is not found` возникает при открытии проекта через домены:
- ❌ `skypath.fun`
- ❌ `admin.skypath.fun`

Но работает нормально через:
- ✅ `www.skypath.fun`

## 🔍 Причина

Эта проблема связана с **кэшированием** или **разными версиями сборки** на сервере:

1. **Разные версии кода на сервере** - возможно, на `www.skypath.fun` развернута новая версия, а на `skypath.fun` и `admin.skypath.fun` - старая версия
2. **Кэширование браузера** - браузер кэширует старую версию JavaScript модулей
3. **Кэширование CDN/прокси** - если используется CDN или прокси-сервер, он может кэшировать старую версию

## ✅ Решение

### Вариант 1: Обновление кода на сервере (если используется развертывание)

Если у вас есть доступ к серверу и код развернут на нем:

```bash
# Подключитесь к серверу
ssh user@your-server

# Перейдите в директорию проекта
cd /path/to/project  # замените на реальный путь

# Обновите код из репозитория
git pull origin main

# Пересоберите проект
npm run build

# Если используете Nginx, скопируйте новую сборку
sudo cp -r dist/* /var/www/skypath-flow/  # замените на реальный путь

# Очистите кэш Nginx (если используется)
sudo systemctl reload nginx

# Если используете PM2, перезапустите процессы
pm2 restart all
```

### Вариант 2: Очистка кэша браузера

Если проблема в кэшировании браузера:

1. **Жесткая перезагрузка страницы:**
   - Windows/Linux: `Ctrl + Shift + R` или `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

2. **Очистка кэша браузера:**
   - Chrome: Настройки → Конфиденциальность → Очистить данные просмотра → Кэшированные изображения и файлы
   - Firefox: Настройки → Конфиденциальность → Удалить данные → Кэш
   - Safari: Разработка → Очистить кэши

3. **Режим инкогнито:**
   - Откройте сайт в режиме инкогнито/приватном режиме для проверки

### Вариант 3: Проверка версии кода на сервере

Проверьте, что на сервере развернута актуальная версия кода:

```bash
# На сервере проверьте наличие функции formatTimeRemaining
grep -n "export const formatTimeRemaining" /path/to/project/src/shared/utils/formatDate.js

# Должна быть строка с экспортом:
# export const formatTimeRemaining = (expiresAt) => {
```

### Вариант 4: Если используется Docker

Если приложение развернуто через Docker:

```bash
# Обновите код
git pull origin main

# Пересоберите и перезапустите контейнеры
docker-compose up -d --build

# Или если используете отдельные команды
docker-compose build
docker-compose up -d
```

## 🔧 Проверка правильности кода

Убедитесь, что в локальной версии кода:

1. ✅ Функция `formatTimeRemaining` экспортируется из `src/shared/utils/formatDate.js`:
   ```javascript
   export const formatTimeRemaining = (expiresAt) => {
     // ... код функции
   }
   ```

2. ✅ Функция импортируется в `src/features/dashboard/components/Dashboard.jsx`:
   ```javascript
   import { formatTimeRemaining, getTimeRemaining } from '../../../shared/utils/formatDate.js'
   ```

3. ✅ Функция используется в компоненте:
   ```javascript
   {formatTimeRemaining(currentUser.expiresAt)}
   ```

## 🎯 Почему работает на www.skypath.fun, но не на других доменах?

Возможные причины:

1. **Разные директории развертывания** - разные домены могут указывать на разные директории на сервере
2. **Разные конфигурации Nginx** - разные домены могут иметь разные настройки кэширования
3. **Разное время развертывания** - `www.skypath.fun` мог быть обновлен позже других доменов
4. **Кэширование CDN** - если используется CDN, разные домены могут иметь разные настройки кэширования

## 📝 Рекомендации

1. **Убедитесь, что все домены обслуживают одну и ту же версию кода**
2. **Используйте единую директорию развертывания для всех доменов**
3. **Настройте правильное кэширование в Nginx/CDN** - для HTML и JS файлов используйте короткое время кэширования или отключите кэширование
4. **Используйте версионирование файлов** - Vite автоматически добавляет хеши к именам файлов, что помогает избежать проблем с кэшированием

## 🔄 После исправления

После обновления кода на сервере:

1. Очистите кэш браузера или используйте жесткую перезагрузку
2. Проверьте работу на всех доменах
3. Если проблема сохраняется, проверьте логи сервера и браузера (консоль разработчика)
