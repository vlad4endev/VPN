## ⚠️ Важные замечания

1. **Custom Claims обновляются только при новом входе**
   - После установки claim пользователь должен перелогиниться
   - Можно принудительно обновить токен через `auth.currentUser.getIdToken(true)`

2. **Размер Custom Claims ограничен**
   - Максимум 1000 байт для всех claims вместе
   - Не храните большие объемы данных в claims

3. **Firestore Rules не могут изменять Claims**
   - Claims устанавливаются только через Firebase Admin SDK
   - Обычно это делается на backend или через Cloud Functions

4. **Обратная совместимость**
   - Добавлена fallback-функция `isAdminFromFirestore()` на случай, если понадобится вернуться к старому способу проверки

## ❓ Проблемы и решения

### Проблема: "permission-denied" при входе администратора
**Решение:** Установите admin claim через скрипт и попросите пользователя перелогиниться

### Проблема: Задержка 300 мс слишком большая
**Решение:** Можно уменьшить в `src/app/App.jsx`, строка с `setTimeout(resolve, 300)`

### Проблема: Скрипт не находит firebase-service-account.json
**Решение:** Убедитесь, что файл находится в `server/firebase-service-account.json` или укажите путь через переменную окружения `FIREBASE_SERVICE_ACCOUNT_PATH`
