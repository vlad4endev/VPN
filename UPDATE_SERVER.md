# 🔄 Обновление кода на сервере

> Простая инструкция для обновления кода на сервере после изменений

---

## 🚀 Быстрый способ (рекомендуется)

### 1. Подключитесь к серверу по SSH

```bash
ssh user@your-server-ip
```

### 2. Перейдите в директорию проекта

```bash
cd /path/to/your/project
# Например: cd ~/skypath-flow или cd /opt/my-frontend
```

### 3. Запустите скрипт обновления

```bash
./quick-update.sh
```

Скрипт автоматически:
- ✅ Получит последние изменения из GitHub
- ✅ Остановит текущие процессы
- ✅ Очистит кеш
- ✅ Перезапустит frontend и backend

---

## 📝 Ручной способ (если скрипт не работает)

### Шаг 1: Получить обновления из GitHub

```bash
# Перейдите в директорию проекта
cd /path/to/your/project

# Сохраните незакоммиченные изменения (если есть)
git stash

# Определите правильную ветку (main или master)
# Скрипт quick-update.sh делает это автоматически
# Вручную:
git fetch origin
git checkout main  # или master, в зависимости от вашего репозитория
git pull origin main
```

### Шаг 2: Остановить текущие процессы

```bash
# Если есть скрипт остановки
./stop-all.sh

# Или вручную
pkill -f "vite.*5173"  # Остановить frontend
pkill -f "n8n-webhook-proxy.js"  # Остановить backend
```

### Шаг 3: Очистить кеш

```bash
rm -rf node_modules/.vite
rm -rf .vite
```

### Шаг 4: Перезапустить службы

```bash
# Если есть скрипт запуска
./start-all.sh

# Или вручную
# Backend
cd server
nohup npm start > ../backend.log 2>&1 &
cd ..

# Frontend
nohup npm run dev > frontend.log 2>&1 &
```

## 🔍 Проверка обновления

### Проверьте логи

```bash
# Логи backend
tail -f backend.log

# Логи frontend
tail -f frontend.log
```

### Проверьте статус процессов

```bash
# Проверка портов
lsof -i :5173  # Frontend
lsof -i :3001  # Backend

# Или через ps
ps aux | grep vite
ps aux | grep node
```

### Проверьте в браузере

1. Откройте приложение в браузере
2. Очистите кеш браузера (Ctrl+Shift+R или Cmd+Shift+R)
3. Проверьте, что ошибка исчезла

---

## ⚠️ Если что-то пошло не так

### Откат к предыдущей версии

```bash
# Посмотреть историю коммитов
git log --oneline -10

# Откатиться к предыдущему коммиту
git reset --hard HEAD~1

# Или к конкретному коммиту
git reset --hard <commit-hash>

# Перезапустить службы
./stop-all.sh
./start-all.sh
```

### Восстановить незакоммиченные изменения

```bash
# Посмотреть сохраненные изменения
git stash list

# Восстановить последние изменения
git stash pop
```

## 📚 Дополнительные скрипты

В проекте есть несколько скриптов для разных задач:

- **`quick-update.sh`** - Быстрое обновление (git pull + перезапуск)
- **`update-server.sh`** - Обновление с проверкой PM2
- **`deploy-ubuntu.sh`** - Полный деплой (установка зависимостей + запуск)
- **`start-all.sh`** - Запуск всех служб
- **`stop-all.sh`** - Остановка всех служб

2. ✅ Проверьте работу приложения в браузере

## 🆘 Проблемы?

Если возникли проблемы:

1. Проверьте логи: `tail -f backend.log` и `tail -f frontend.log`
2. Убедитесь, что все зависимости установлены: `npm install`
3. Проверьте, что порты свободны: `lsof -i :5173` и `lsof -i :3001`
4. Убедитесь, что файл `.env` настроен правильно
