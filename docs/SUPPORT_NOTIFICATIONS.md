# Уведомления по тикетам поддержки

## Админ получает уведомления в Telegram

Когда пользователь создаёт тикет или пишет новое сообщение в тикете, админу отправляется сообщение в Telegram.

### Настройка

1. **Токен бота** — уже используется для привязки и напоминаний (см. Telegram в админке или `TELEGRAM_BOT_TOKEN` в `server/.env`).

2. **Chat ID админа** — куда слать уведомления о тикетах:
   - В `server/.env`: `TELEGRAM_ADMIN_CHAT_ID=123456789` (узнать свой ID: @userinfobot в Telegram).
   - Либо сохранить в Firestore: в настройках Telegram в админке передать в PATCH `api/admin/telegram/settings` поле `adminChatId` (или добавить поле в UI настроек Telegram). В Firestore путь: `artifacts/{APP_ID}/public/settings` → поле `telegramAdminChatId`.

После настройки запросы с фронта на `POST /api/notify/support-ticket` будут слать админу сообщения вида: «Новый тикет» / «Новое сообщение в тикете» с темой и текстом.

---

## Пользователь получает уведомление об ответе поддержки

1. **Telegram** — если у пользователя в профиле привязан Telegram (`tgId`), ответ поддержки дублируется ему в личку от бота.
2. **Браузерный push** — если пользователь разрешил уведомления в браузере и открыт раздел «Тех. поддержка», при новом ответе от поддержки показывается браузерное уведомление «Ответ поддержки».

Привязка Telegram делается в личном кабинете (если включена интеграция с ботом).
