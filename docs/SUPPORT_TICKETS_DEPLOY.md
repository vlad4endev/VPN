# Деплой правил Firestore для тикетов поддержки

Ошибка **«Missing or insufficient permissions»** в разделе «Тех. поддержка» возникает, если правила Firestore с тикетами не задеплоены в ваш проект Firebase.

## Что сделать

1. Установите Firebase CLI (если ещё не установлен):
   ```bash
   npm install -g firebase-tools
   ```

2. Войдите в аккаунт (если ещё не вошли):
   ```bash
   firebase login
   ```

3. Задеплойте только правила Firestore:
   ```bash
   cd /путь/к/проекту/VPN
   firebase deploy --only firestore:rules
   ```

После успешного деплоя правила из файла `firestore.rules` (включая блоки для `tickets` и `messages`) начнут применяться, и тикеты должны заработать.

## Проверка

- Откройте [Firebase Console](https://console.firebase.google.com) → ваш проект → Firestore Database → Rules.
- Убедитесь, что в правилах есть блоки `match /artifacts/{appId}/public/data/tickets/...` и `.../tickets/{ticketId}/messages/...`.

## Уведомления в фоне (Web Push)

Чтобы пользователи получали push **при закрытой вкладке**, на бэкенде задайте VAPID-ключи в `server/.env`:

```bash
npx web-push generate-vapid-keys
# Вписать VAPID_PUBLIC_KEY и VAPID_PRIVATE_KEY в server/.env
```

Одна и та же подписка используется для:
- **Ответы поддержки** — при открытии раздела «Тех. поддержка» браузер подписывается на push; сервер шлёт уведомления при ответе (плюс Telegram).
- **Рассылки из админки** — при рассылке уведомлений каждому получателю дополнительно отправляется Web Push.
- **Подписка активирована** — после успешной оплаты пользователю уходит Web Push (плюс запись в центр уведомлений и при желании Telegram).

Подписка на push регистрируется при открытии раздела поддержки или при работе с центром уведомлений (колокольчик) в личном кабинете, если пользователь уже разрешил уведомления.
