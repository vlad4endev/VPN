# Исправления от 2026-03-05

## Проблемы и решения

### 1. **Dashboard: tariffs undefined → TypeError .find()**
- **Причина:** Dashboard не получал пропсы `tariffs`, `settings`, `servers` из App.jsx
- **Решение:** Добавлены `tariffs={tariffs ?? []}`, `settings={settings}`, `servers={servers ?? []}` при рендере Dashboard
- **Дополнительно:** В Dashboard введена переменная `tariffsList = Array.isArray(tariffs) ? tariffs : []` и все вызовы `.find()`, `.filter()`, `.map()` переведены на неё

### 2. **Порядок загрузки данных для Dashboard**
- **Причина:** Тарифы и настройки загружались только при открытии админки, обычные пользователи видели пустой кабинет
- **Решение:**
  - Добавлен эффект: при `view === 'dashboard'` и `currentUser` вызываются `loadTariffs()` и `loadPublicSettings()`
  - `loadPublicSettings()` — загрузка settings и servers для обычных пользователей (чтение из Firestore `artifacts/{appId}/public/settings`)

### 3. **Auth: ReferenceError view is not defined**
- **Причина:** В useAppAuth использовалась переменная `view`, которая не передавалась в хук
- **Решение:** Условие логирования заменено на `isBrowserAuthPath(path)` без проверки `view`

### 4. **Auth: TDZ (Cannot access before initialization)**
- **Причина:** useTelegramInit вызывался с `loadUserData` и `setCurrentUser` до их объявления
- **Решение:** setCurrentUser и useAppAuth перенесены выше useTelegramInit в App.jsx

### 5. **Auth: setViewState в useAppAuth**
- **Причина:** В useAppAuth вызывался несуществующий `setViewState`
- **Решение:** Заменён на `setView`

## Что проверить

1. **Firestore Rules:** Должен быть доступ на чтение:
   - `artifacts/{appId}/public/data/tariffs` — для всех авторизованных
   - `artifacts/{appId}/public/settings` — для всех авторизованных (или только публичные поля)
   - `artifacts/{appId}/public/data/users_v4/{userId}` — только свой документ

2. **VITE_API_BASE_URL:** Должен указывать на рабочий API (например `https://skypath.fun` в production)

3. **Firebase Admin на сервере:** Для `ensure-firestore-user` и `resolve-login` нужен `server/firebase-service-account.json` или переменные окружения
