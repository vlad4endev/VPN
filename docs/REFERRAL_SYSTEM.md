# Реферальная система

## Обзор

- Пользователю при первом заходе в личный кабинет генерируется **уникальный реферальный код** (8 символов) и сохраняется в документе пользователя в Firestore.
- **Реферальная ссылка**: `https://ваш-домен/?ref=КОД` (или путь страницы + `?ref=КОД`).
- Друг переходит по ссылке или вводит код при регистрации; после **успешной регистрации** (email или Google) пригласивший получает **бонусные баллы** один раз за каждого приглашённого.
- Ограничение: бонус начисляется **только один раз на одного приглашённого** (учёт в коллекции `referral_rewards`).

## Реализация

### Фронтенд

- **Чтение `?ref=`**: при загрузке приложения параметр `ref` из URL сохраняется в state и в `sessionStorage`, чтобы не потерять код при переходах (в т.ч. на Google Sign-In).
- **Регистрация**: при создании пользователя (email или Google) в документ пользователя записывается `referredBy: inviterId` (если код валидный). После записи в Firestore вызывается `POST /api/referral/process` с idToken приглашённого — бэкенд начисляет бонус пригласителю.
- **Личный кабинет**: в разделе «Подписки» отображается блок «Пригласи друга»: реферальная ссылка, код и текущий реферальный баланс (баллы).

### Бэкенд

- **POST /api/referral/process**  
  - Header: `Authorization: Bearer <Firebase ID token>` (токен приглашённого).  
  - Body: `{ referredUserId, inviterId }`.  
  - Проверки: токен соответствует `referredUserId`; в документе пользователя `referredUserId` поле `referredBy === inviterId`; для этого приглашённого ещё не создана запись в `referral_rewards`.  
  - Действия: создаётся документ в `artifacts/{appId}/public/data/referral_rewards/{referredUserId}`; у пригласителя увеличивается `referralBonusBalance` на сумму бонуса (по умолчанию 100, задаётся через `REFERRAL_BONUS_AMOUNT` в .env сервера).

### Firestore

- **users_v4**: опциональные поля `referralCode`, `referredBy`, `referralBonusBalance`.  
  - `referralCode` — уникальный код пользователя (владелец может обновить при создании кода через сервис).  
  - `referredBy` — uid пригласителя (только при создании документа, если регистрация по реферальной ссылке).  
  - `referralBonusBalance` — обновляется только бэкендом (Admin SDK).
- **referral_rewards**: коллекция, ключ документа — `referredUserId`. Поля: `inviterId`, `referredUserId`, `bonusAmount`, `bonusGrantedAt`. Доступ только с бэкенда (правила Firestore: `allow read, write: if false`).

### Константы

- Размер кода: 8 символов (см. `src/shared/constants/referral.js`).
- Сумма бонуса по умолчанию: 100 баллов (бэкенд: `REFERRAL_BONUS_AMOUNT` в .env или 100).

## Использование баллов

Текущая реализация только **накапливает** баллы в `referralBonusBalance`. Списание баллов (скидка при оплате, кредит и т.д.) можно добавить отдельно в логику оплаты/тарифов.
